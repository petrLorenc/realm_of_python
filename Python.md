# Python Learning Path

## 🎯 How to Learn Effectively

1. **Find a project** - Having a clear goal prevents aimless browsing. *Your project determines which technologies to learn!*
2. **Find a mentor** - Get guidance on what to learn and when
3. **Practice consistently!**

💡 *Need guidance? Visit [petr.budaktivni.cz/en](https://petr.budaktivni.cz/en) for mentorship and consultancy.*

## 📚 Skills by Development Stage

### **Scripts** (Local/Colab)
Running code on your machine - Python, JavaScript, environment setup, file I/O

### **Applications** (Cloud)
Deploying to AWS, GCP, Azure - networking, system architecture, multi-tech solutions

### **Services** (Cloud)
Containerization with Docker/Kubernetes, DevOps practices, observability

### **Additional Skills** (As Needed)
Databases • ML/LLM • Web Development • Data Science
